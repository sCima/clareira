Sites que você atravessa.

Profundo.js transforma a rolagem em uma viagem 3D. Você descreve a cena com tags HTML, como <pf-text> e <pf-wall>, e a biblioteca monta o túnel, a câmera, o vidro e as ondas em cima do three.js.

Seu primeiro mergulho

Um elemento com data-profundo vira o trilho. A altura dele define quanto se rola, e as tags <pf-*> dentro dele dizem o que aparece e a que profundidade, em metros.

<div data-profundo data-length="600vh" data-depth="400" data-hud>
  <pf-gate word="OLÁ"></pf-gate>
  <pf-portals from="40" to="320"></pf-portals>
  <pf-dust></pf-dust>
  <pf-text at="80">Meu primeiro<br>mergulho.</pf-text>
  <pf-glass-field from="150" to="260"></pf-glass-field>
  <pf-wall at="340" word="FIM"></pf-wall>
  <pf-sun at="520"></pf-sun>
</div>

<section style="position:relative; z-index:2">
  <!-- o resto do seu site continua aqui, por cima da cena -->
</section>

Não precisa de JavaScript próprio. A biblioteca procura [data-profundo] quando a página carrega e monta tudo sozinha. O texto das tags continua no HTML, então leitores de tela e buscadores leem a história normalmente.

Instalação

Profundo.js depende do three.js e de mais nada. Carregue o three antes da biblioteca.

<link rel="stylesheet" href="profundo.css">
<script src="https://cdn.jsdelivr.net/npm/three@0.158.0/build/three.min.js"></script>
<script src="profundo.js"></script>
Ainda não está no npmPor enquanto, copie a pasta dist/ (profundo.js e profundo.css) para o seu projeto. O arquivo funciona como script comum e também com require().

A fonte padrão das palavras 3D é a Anybody, do Google Fonts. Sem ela, a biblioteca usa uma fonte condensada do sistema. Para trocar, use data-font ou a opção font.

Se você usa three como módulo (r160 em diante), passe a referência: Profundo.create({ three: THREE }).

Tags

Toda posição é em metros de profundidade. at="200" quer dizer 200 metros à frente do início. x e y deslocam para os lados e para cima.

API em JavaScript

Tudo o que as tags fazem também existe como função. Use a API para montar cenas por código, reagir à rolagem ou colocar seus próprios objetos 3D no túnel.

<script src="profundo.js" data-manual></script>  // data-manual desliga a montagem automática

const pf = Profundo.create({ track: '#trilho', length: '800vh', depth: 600, hud: 'MEU SITE' });

pf.add(
  Profundo.gate({ word: 'MERGULHE' }),
  Profundo.portals({ from: 40, to: 520 }),
  Profundo.text({ at: 90, text: 'Olá,\nprofundidade.', gradient: ['#ffb648', '#ff5d73'] }),
  Profundo.glassField({ from: 200, to: 360, count: 20 }),
  Profundo.wall({ at: 560, word: 'FIM' }),
  Profundo.chapter(0, 'Início'), Profundo.chapter(200, 'Vidro')
);

// seu próprio objeto three.js, girando no metro 300
pf.add(Profundo.custom({
  at: 300,
  create: (THREE) => new THREE.Mesh(new THREE.TorusKnotGeometry(2, .5), new THREE.MeshNormalMaterial()),
  update: (obj, { dt }) => { obj.rotation.y += dt; },
  wave: (obj) => obj.scale.setScalar(1.4)
}));

pf.on('chapter', (cap) => console.log('entrou em', cap?.name));

Métodos e eventos

MétodoFaz
add(...elementos)Coloca elementos na cena. Aceita listas.
goTo(metros, { duration })Rola até uma profundidade com animação. goTo(0) volta à superfície.
wave(x, y)Dispara uma onda num ponto da tela.
on(evento, fn) / offEscuta progress, chapter e wave.
destroy()Remove a cena, o HUD e os ouvintes.
three{ THREE, renderer, scene, camera } para quem quiser ir além.
Profundo.tilt(alvo)Inclinação 3D com brilho que segue o mouse. O atributo data-pf-tilt faz o mesmo.

O evento progress chega a cada quadro com { progress, depth, speed }. Use isso para sincronizar a sua interface com o mergulho. A instância criada pelo HTML fica em elemento.profundo.

Vidro na interface

A classe pf-glass é o vidro para elementos HTML: desfoque, saturação, borda de luz e um brilho que segue o mouse. Junto com data-pf-tilt, o cartão inclina em 3D.

.pf-glass
+ data-pf-tilt
--pf-glass-blur: 6px

Ajuste com variáveis CSS: --pf-glass, --pf-glass-hi, --pf-glass-line, --pf-glass-tint e --pf-glass-blur.

Acessibilidade e desempenho

  • O conteúdo continua no HTML. O texto das tags fica disponível para leitores de tela e buscadores. O canvas é marcado como decorativo.
  • Movimento reduzido é respeitado. Com a preferência ligada no sistema, somem a paralaxe, o balanço, a dobra de velocidade e as animações automáticas. A rolagem continua funcionando.
  • Cliques em controles não viram onda. Links, botões e campos funcionam normalmente. Use data-pf-nowave para proteger outras áreas.
  • A cena para quando não aparece. Ela pausa com a aba escondida e quando você já rolou bem além do trilho.
  • Sem WebGL, sem susto. A página ganha a classe pf-no-gl e um fundo em gradiente, e o resto do site segue normal.
  • Vidro custa caro. Cada peça renderiza a cena de novo para refratar. No celular, o campo de vidro já cai para 16 peças. Prefira até 30 no total.
