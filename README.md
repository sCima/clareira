# Clareira

Loja conceito de plantas e vasos de barro feita com o [Profundo.js](profundo/). A rolagem atravessa uma trilha 3D pela mata até a clareira, onde um simulador de janela indica a planta certa para a luz da casa.

- `index.html`: a loja
- `arte.js`: ilustrações botânicas desenhadas em canvas
- `profundo/`: a biblioteca, a documentação e o exemplo do mergulho

Produtos, preços e políticas são fictícios.

```bash
npx http-server@14.1.1 . -p 5173 -c-1
```
